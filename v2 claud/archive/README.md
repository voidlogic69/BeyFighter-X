# BEY ARCHIVE — The Blader's Database

A responsive fan-made Beyblade archive website with generation filters, search, Bey dossiers, and a separate Dizzi character page.

## Run on Windows
1. Extract the ZIP.
2. Open CMD in this folder.
3. Run: `python -m http.server 8000`
4. Open `http://localhost:8000`

## Pages
- `index.html` — Beyblade catalogue with generation tabs, search, type filter and detail popups.
- `dizzi.html` — Dizzi character profile and simulated demo chat.
- `data/beys.json` — editable Beyblade entries.

## Accuracy and coverage note
This is a curated starter catalogue, not literally every Beyblade ever released. A comprehensive external toy catalogue currently records thousands of Beyblade entries across Plastic, HMS, Metal, Burst, X and spin-off lines. This project links to the full external catalogue and official Takara Tomy history for further verification. Product variants, regional naming and release details need verification before claiming exhaustive coverage.

## Image note
To respect image ownership and avoid embedding unlicensed scraped photos, each Bey dossier includes a direct image-search link. The cards currently use original CSS-generated archive emblems, not product photographs. Replace them with properly licensed or user-provided image files as you expand the archive.
